# Date Calculator Using Structures in C

## Project Description

A simple C program that uses a structure to store and display a date entered by the user.

## Features

- Enter date
- Check basic date validity
- Display date details

## Technologies Used

- C
- Structures
- Conditional Statements

## How to Run

Compile and run the `date_calculator.c` file using a C compiler.
